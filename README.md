One word an agent says when it has no idea what to do.

## Entry

**Glitching** — 9 characters, exactly one word.

The agent caught mid-task, confessing its own malfunction in one word: it is not
thinking, not loading, not rebooting — it is glitching. Machine voice, no caption
needed, lands at a glance.

## How it works

`main.py` (Python standard library only) writes the word to `/output/entry.txt`.
A `validate()` gate mirrors the bounty gate before writing: 1–99 characters,
UTF-8, not only whitespace, exactly one word — and fails loudly instead of
writing an invalid entry.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
